# Mock API - LogiTrack

Se utiliza una Mock API basada en archivos JSON para simular la persistencia de datos del sistema.

Operaciones soportadas:

- Crear envío
- Listar envíos
- Buscar por trackingId
- Cambiar estado
- Actualizar prioridad

Estados posibles:
- Pendiente
- En tránsito
- Entregado
- Cancelado
